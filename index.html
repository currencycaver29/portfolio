NLP Research01

The Token Tax on Indian Languages

How many more tokens the 22 scheduled Indian languages need than English, measured across 14 tokenizers from GPT-4o and Llama 4 to India's own Sarvam-1.

The Problem

LLM cost, context length and speed are all counted in tokens, and tokenizers built on English-heavy data split Indian languages into far more of them.

Key Decisions

Used professionally translated parallel sentences, verified GPT counts against OpenAI's official tiktoken (catching a 46% library over-count), and excluded tokenizers that silently drop text.

Distributed ML02

Low-Communication Training over Bad Networks

DDP vs DiLoCo vs hierarchical aggregation for training a transformer across emulated regions, measured over real TCP through a packet-level WAN emulator.

The Problem

Training across distant sites is limited by slow, lossy internet links, and most studies estimate network effects instead of measuring them.

Key Decisions

Built an NFQUEUE emulator with per-region full-duplex links and real MTU, found and fixed a TCP Small Queues artefact, tuned every baseline fairly and validated with a real 4-process run.

IoT Networking03

MQTT, CoAP & HTTP on Bad Networks

A reproducible benchmark of the three main IoT protocols under emulated 4G, 3G, 2G and lossy links, with JSON and CBOR payloads.

The Problem

IoT devices often live on patchy cellular links, but protocol comparisons are usually run on clean networks.

Key Decisions

Packet captures exposed configuration pitfalls (no keep-alive, Nagle, autocorking) that made HTTP look 4× slower than it is; every contaminated run was repeated.

How I build AI systems

I treat machine learning as an engineering system that has to survive the real world, not just a model that scores well in a notebook. I start from a concrete constraint, such as a slow network, a small device or an under-served language, and recreate it as faithfully as I can. I measure with repeated seeds, check every number against a reference implementation, give every baseline its best settings, and publish the code, data and limitations so anyone can rerun the work.
